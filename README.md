# SvelteKit Login Application

A simple login page built with SvelteKit and Svelte.

## Features

- Clean and responsive login form
- Email and password validation
- Mock authentication with dummy data
- Error handling
- Loading states
- Modern UI with gradient background

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```
